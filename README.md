# 준영 인생 단톡방

준영의 인생이 한 해 한 해 **실시간으로 올라오는 단톡방.**

들어오는 말풍선은 지금 벌어지는 일, 나가는 말풍선은 준영이 한 말이다.
화면에서 유일하게 밝은 색이 준영의 말풍선인 건 의도다 — 이 게임의 주인공은 그의 입담이니까.

**엔진 형식**은 [도시의 한 사람으로 태어나](https://project-moon-life.cityborn.workers.dev/)에서 가져왔다
(실시간 나이 진행, 타이머 선택지, 선언적 이벤트 데이터 — [docs/REFERENCE-FORMAT.md](docs/REFERENCE-FORMAT.md)).
**겉모습과 용어는 전부 갈아엎었다:**

| 레퍼런스 | 이 게임 |
|---|---|
| 어두운 명조체 서술 로그 | 단톡방 타임라인 |
| 선택지 모달 | 하단 답장 후보 칩 |
| 수집 코덱스 | 사진 모아보기 |
| 나이 표시 | 날짜 구분선 (`스물일곱 살`) |
| 출생지 선택 | **출생지 랜덤** (시드에서 결정) |
| 죽음 카드 | **"준영님이 나갔습니다"** |

```bash
npm run dev          # 개발 서버
npm run test:engine  # 엔진 검증 (100생 시뮬 + 결정론 + 불변식)
npm run build        # 프로덕션 빌드
```

## ⚠️ 사진은 저장소에 없습니다

이 저장소는 공개라서 준영 사진을 커밋하지 않습니다 (`.gitignore`에 `img/`, `public/photos/`).

- 사진 없이도 게임은 정상으로 돌아갑니다. 자리에 "사진을 불러오지 못했어요"가 뜹니다.
- 사진을 보려면 원본을 `img/`에 넣고 아래로 웹용을 만드세요.

```bash
mkdir -p public/photos
i=0; for f in img/*; do i=$((i+1))
  sips -Z 1000 -s format jpeg -s formatOptions 70 "$f" \
    --out "public/photos/photo-$(printf '%02d' $i).jpg"
done
```

파일 이름과 `lib/content/photos.ts`의 `photo-NN` 번호가 맞아야 합니다.

## 핵심 감각

| | |
|---|---|
| 1년 | 실시간 15초 (`YEAR_MS`) |
| 배속 | ×1 / ×2 / ×4 / ×8 / ×16 |
| minor 선택 | **10초 타이머**, 무응답 시 `흘려보낸다` |
| major 선택 | **타이머 없음** — 시간이 멈추고 기다린다 |
| 스탯 | 체력·멘탈·**입담**·자금·인맥·평판, 1~100 |
| 수명 상한 | 100세 |
| 출생지 | **고를 수 없음.** 시드에서 가중치로 걸린다 |

## 이벤트 추가하기

`lib/content/events.ts`에 객체 하나 넣으면 끝. 로직은 건드릴 필요 없다.

```ts
{
  id: "s_exam",            // 고유 id
  age: [17, 19],           // 발동 나이 구간
  major: true,             // 타이머 없이 대기 (인생을 가르는 선택)
  force: true,             // 이 구간에 반드시 한 번
  forceGroup: "career",    // 같은 그룹은 하나만 (배타 분기)
  requires: ["진학"],       // 플래그 조건
  needs: { money: 30 },    // 스탯 하한
  text: "시험 전날 새벽 두 시. ...",
  choices: [
    // 결과 확정형
    { label: "자고 아침에 승부한다", text: "...", eff: { h: 4, m: 2 } },
    // 가중치 난수형 — w는 확률이 아니라 가중치
    { label: "끝까지 버틴다", outcomes: [
      { w: 45, text: "...", eff: { r: 12 }, flagsAdd: ["벼락치기성공"] },
      { w: 55, text: "...", eff: { m: -10 }, tone: "bad" },
    ]},
  ],
  ignore: { text: "그냥 잤다.", eff: { r: -3 } },   // 흘려보냈을 때
}
```

`eff` 축약키: **h**체력 **m**멘탈 **t**입담 **w**자금 **f**인맥 **r**평판
그 외 필드: `repeat`/`cooldown`(재발동) `forbids` `rare`(금색 강조) `flagsAdd`
`death`(즉사 사인) `next`(체인) `flavor`(선택지 없는 서술) `photo`(사진첩에 꽂기)

### 입담 장치

준영의 주특기라서 스탯으로 만들었다. `needs: { wit: 60 }` 을 선택지에 걸면
**입담이 낮을 땐 그 선택지가 아예 안 보인다.** "농담으로 넘긴다" 류가 전부 이걸로 잠겨 있다.

### 사진

`lib/content/photos.ts` 에 등록하고 이벤트에 `photo: "<id>"` 를 달면
로그에 폴라로이드로 꽂히고 그 생의 사진첩에 수집된다.
원본 `img/` 130MB → `public/photos/` 4.8MB (1000px/q70, gif는 mp4로).
